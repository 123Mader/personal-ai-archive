# 目录说明：workflow / 工作习惯与协作规则

本目录存放「我怎么工作、怎么和AI协作」的规则：工作习惯、常用工具、沟通风格、任务优先级。
属于 **AI-READONLY（只读保护）** 区域为主——这些是你的稳定协作偏好，AI 应严格遵守、不应擅自改写规则本身。
其中 `tools.md` 设有 AI 建议区，AI 可在此追加新工具建议（仍经版本记录留痕）。

## 包含文件
| 文件 | 内容 | AI 权限 |
|------|------|---------|
| `work-habits.md` | 工作习惯、专注时段 | READONLY |
| `tools.md` | 常用工具清单、AI 建议区 | READONLY + 建议区可追加 |
| `communication-style.md` | 常用沟通风格、回复格式偏好 | READONLY |
| `task-priorities.md` | 任务优先级判定规则 | READONLY |

## AI 使用约定
- AI 在规划任务、生成回复时，必须先读取本目录对齐你的协作偏好。
- 规则的任何修改须人工确认后提交，触发版本快照。
