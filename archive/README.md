# 目录说明：archive / 历史归档

本目录归档历史项目、旧文档、已完成的任务，作为可检索的历史资产。
属于 **AI-READWRITE** 区域——AI 可将已完结事项追加归档，保留时间线。

## 包含文件
| 文件 | 内容 | AI 权限 |
|------|------|---------|
| `projects.md` | 历史项目索引与一句话总结 | READWRITE |
| `completed-tasks.md` | 已完成任务的归档记录 | READWRITE |

## AI 使用约定
- 归档仅追加，不删除历史条目；若项目状态变更，在原条目下新增「状态更新」行。
- 归档目的：让AI在接到类似任务时，能先查历史资产避免重复劳动。
