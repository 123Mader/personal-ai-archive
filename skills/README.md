# 目录说明：skills / 技能与学习

本目录记录「我能做什么、在学什么、想补什么」。属于 **AI-READWRITE** 区域。
AI 可在技能取得进展时追加更新（掌握新技能、更新学习进度、移除已补足能力），
更新须提交版本记录，历史可回退。

## 包含文件
| 文件 | 内容 | AI 权限 |
|------|------|---------|
| `mastered-skills.md` | 已掌握的技能清单 | READWRITE |
| `learning-plan.md` | 当前学习计划与进度 | READWRITE |
| `to-improve.md` | 待提升的能力清单 | READWRITE |

## AI 使用约定
- AI 在接受技能相关任务时，先读本目录判断你的现有能力，避免重复教学。
- 更新时维持「技能名 + 熟练度 + 证据/出处」结构，便于跨AI一致。
